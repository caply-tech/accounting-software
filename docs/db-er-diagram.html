core.db — the shared registry

One file for the whole installation. businesses, users and roles are the three parent lists everything else here points back to.

biz_<id>.db — Accounts & Finance

One instance of this whole schema per business. chart_of_accounts, journal_entries, bank_accounts and invoices are parents; budgets stands alone.
